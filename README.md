# Exploring PFNs
This is my exploratory repository for the field of Bayesian Inference Prior-Fitted Networks and their possible uses in Transformers.

### Get started
**Setting up the environment:**
```bash
uv sync
```

**Important Files**
- `bayesian/bayesian_update.ipynb`
    Small simulation of how bayesian updates can be used to test hypotheses. Two coins, one biased and one fair are tested, with initially same priors but different probabilities.
